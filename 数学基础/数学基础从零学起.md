## 开篇：这些数学在 LLM 里各管什么（一张地图）

先别急着学，先知道"学它们干什么"。这五个工具，正好对应课程里五类公式：

| 数学工具          | 一句话             | 课程里用到的地方                      |
| ------------- | --------------- | ----------------------------- |
| **sin / cos** | 画圆、描述"旋转"和"周期"  | 第 1 讲位置编码、第 2 讲 RoPE          |
| **log 对数**    | 把"乘法"变成"加法"     | 交叉熵、缩放定律、KL 散度                |
| **积分 ∫**      | "求和"的连续版（曲线下面积） | policy gradient 里的期望 `E[...]` |

## 第 0 章：读公式的基本功（先会"念"公式）

小白最大的障碍不是"算不对"，而是"看不懂符号"。先花 3 分钟认全符号，后面一路顺。

### 0.1 变量：一个"会变的盒子"

```
x = 5
```

`x` 是一个**盒子**，里面装了一个数，现在装的是 5。盒子可以随时换东西：

```
x = 5
x = 8    ← 现在盒子里是 8 了
```

数学书里满屏的 `x`、`y`、`θ`、`d`，全是这种"装数的盒子"，只是名字不同而已。**看到陌生字母，心里默念"这是一个数/一个盒子"，就不慌了。**

### 0.2 等号：左右两边"一样多"

```
3 + 2 = 5
```

等号不是"计算出结果"，而是"**左边和右边是同一个东西**"。所以它可以两边同时加、减、乘同一个数而不破坏平衡——后面推导全在干这件事。

### 0.3 下标：第几个

```
x₁  x₂  x₃
```

就是"第一个 x、第二个 x、第三个 x"。`xᵢ` 表示"第 i 个"。课程里 `Q`、`K`、`V` 都是带下标的一大堆数。

### 0.4 Σ（求和符号）：自动累加

```
Σ xᵢ  =  x₁ + x₂ + x₃ + … + xₙ
```

大写希腊字母 Σ（读"西格玛"）就是"**把一堆东西全加起来**"的缩写。它上面、下面会标"从哪加到哪"，比如：

```
  5
  Σ  i  =  1 + 2 + 3 + 4 + 5  =  15
 i=1
```

读法：i 从 1 加到 5。**Σ 就是"连加"的简写，没有别的玄机。**

### 0.5 乘号可以省略

```
ab  =  a × b        （两个字母挨着 = 相乘）
2x  =  2 × x
Q·Kᵀ                  （点 · 也是相乘）
```

`QKᵀ`、`softmax(QKᵀ/√dₖ)` 里的字母挨着，就是相乘。这是论文里最常见的写法，认出来就行。

### 0.6 分数和根号（一眼认）

```
a/b   =  a ÷ b        （分数线就是除号）
√d    =  d 的平方根   （√9 = 3，因为 3×3=9）
```

`√dₖ` 就是"dₖ 开平方"。比如 dₖ=64，`√64 = 8`。

> 好，符号认全了。下面正式进入五个数学工具，每个都从"小学生能懂"开始。

## 第 1 章：sin 和 cos（正弦与余弦）

### 1.1 一句话直觉

**sin 和 cos 就是"转圈时，你的高度和横向位置"。** 你绕着单位圆（半径 = 1 的圆）转，转到某个角度时：

- **cos(θ)** = 你此刻的**横坐标**（左右位置）
- **sin(θ)** = 你此刻的**纵坐标**（上下位置）

记住这一句，整个 LLM 里的 sin/cos 就都通了。

### 1.2 从直角三角形说起（最原始的定义）

先看一个直角三角形（有一个角是 90°）。拿其中一个锐角（尖角）叫它 `θ`（读"西塔"，就是"某个角度"的意思）：

```
        /|
       / |
   斜边/  | 对边（θ 对面的那条边）
     /   |
    /θ___|
     邻边（θ 挨着的那条边）
```

定义：

```
sin(θ) = 对边 ÷ 斜边
cos(θ) = 邻边 ÷ 斜边
```

**例子（超具体）**：假设 θ = 30°，斜边 = 2，对边 = 1，邻边 = √3 ≈ 1.73：

```
sin(30°) = 1 ÷ 2 = 0.5
cos(30°) = 1.73 ÷ 2 ≈ 0.87
```

这就是 sin、cos 的全部"计算"——**就是两条边的比值**，不是什么神秘的东西。

### 1.3 升级到单位圆（LLM 里真正用的版本）

直角三角形的问题：角度最大只能到 90°，而且比值会随着斜边长度变。数学上更爱用**单位圆**（半径固定为 1 的圆）：

```
        90°
         |
    sin  |   .  ← 一个点，半径=1
         |  /
         | /   ← 这个角就是 θ
   ------+-----> 0°
         |cos
```

- 圆上任取一个点，它和圆心连线的角度是 `θ`；
- 这个点的**横坐标就是 cos(θ)**，**纵坐标就是 sin(θ)**；
- 因为半径 = 1，所以斜边永远是 1，定义就简化成：`sin(θ)=对边/1=对边`，`cos(θ)=邻边/1=邻边`。

**这解释了一个关键性质：sin 和 cos 的值永远在 −1 到 1 之间**（因为单位圆上点的坐标都在 −1~1 之间）。

```
-1 ≤ sin(θ) ≤ 1        -1 ≤ cos(θ) ≤ 1
```

### 1.4 三个必须记住的性质（每个都配例子）

**性质 1：周期性（转一圈又回来）**

转 360° 回到原点，所以：

```
sin(θ + 360°) = sin(θ)
```

例：`sin(30°) = sin(390°) = 0.5`。这就是"周期"，课程里说"位置编码的周期性"就是指这个。

**性质 2：勾股定理 → sin² + cos² = 1**

单位圆上任何点，横坐标² + 纵坐标² = 半径² = 1：

```
sin²(θ) + cos²(θ) = 1
```

（`sin²θ` 是 `(sin θ)²` 的简写，先算 sin 再平方。）

验证：θ=30°，`0.5² + 0.87² = 0.25 + 0.75 = 1` ✓

**性质 3：角度用什么单位——弧度**

数学里角度不用"度"，用"**弧度**"。规则极简单：

```
一整圈 360° = 2π 弧度        （π ≈ 3.14159）
```

换算：`弧度 = 度数 × π / 180`。例：`180° = π`，`90° = π/2`，`30° = π/6`。

> 为什么 LLM 公式里写 `sin(pos/10000^...)` 而不是 `sin(30°)`？因为那个括号里算出来的是**弧度**，不是度数。认个脸熟即可。

### 1.5 它在 LLM 里的用途 ①：位置编码（第 1 讲）

第 1 讲的位置编码公式（你现在能读懂了）：

```
PE(pos, 2i)   = sin( pos / 10000^(2i/d) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d) )
```

**逐字翻译**：

- `pos`：这个词排第几个（第 0、1、2……位）
- `d`：词向量的总维度（比如 512）
- `i`：当前在算第几对维度（0、1、2……）
- `2i`：偶数维（第 0、2、4……维），用 **sin**
- `2i+1`：奇数维（第 1、3、5……维），用 **cos**

**推导一个具体数字**：假设 d=512，算第 0 个词（pos=0）的第 0 维（i=0，偶数维，用 sin）：

```
PE(0, 0) = sin( 0 / 10000^(2×0/512) )
         = sin( 0 / 10000^0 )
         = sin( 0 / 1 )
         = sin(0)
         = 0
```

算第 1 个词（pos=1）的第 0 维：

```
PE(1, 0) = sin( 1 / 10000^0 ) = sin(1) ≈ 0.84   ← 1 是弧度，约 57°
```

**为什么用 sin/cos 而不是随便编几个数？** 三个理由，现在你都能理解了：

1. **有界**：值永远在 [−1, 1]，不会越加越大把数值搞炸（sin/cos 性质 1）；
2. **唯一且连续**：不同 pos 给出不同的一串数，但相邻 pos 很接近（圆上相邻角度位置相邻）；
3. **能表达"相对距离"**：因为 sin/cos 有周期性，`PE(pos+k)` 可以写成 `PE(pos)` 的某种线性组合——模型能算出"谁在谁后面第几位"。

### 1.6 它在 LLM 里的用途 ②：RoPE 旋转（第 2 讲）

第 2 讲说 RoPE 是"**把位置旋进向量里**"。现在你能懂"旋"这个字了：

- 二维平面里，把向量旋转一个角度 θ，数学上正好用到 sin 和 cos（旋转公式 `x' = x·cosθ − y·sinθ`，`y' = x·sinθ + y·cosθ`）；
- RoPE 把每个 token 的 q、k 向量按"它的位置角度"**旋转**，位置靠后的转得多、靠前的转得少；
- 两个向量都转完后再做点积，结果就**只跟"两个位置的角度差"有关**——这就是"相对位置"。

**sin/cos 在这里的贡献**：给"旋转"这件事提供了计算工具。没有 sin/cos，"把向量转一个角度"就没法用公式表达。

> 小结（记这一句）：**sin = 纵坐标 = 转圈时的高度，cos = 横坐标 = 转圈时的左右位置，值都在 −1~1，会周期性重复。** LLM 用它给"词的位置"和"旋转"编码。

## 第 2 章：log（对数）

### 2.1 一句话直觉

**log 是"乘法的逆运算"，它的超能力是把"乘法变成加法"。** 这对计算机极其重要——因为"很多小数连乘"会下溢成 0，而"连加"永远不会。

### 2.2 定义：log 在问"几次方"

先回顾**幂（次方）**：`2³ = 2×2×2 = 8`，读作"2 的 3 次方"。底是 2，指数是 3，结果是 8。

**log 就是反过来问**：

```
log₂(8) = 3     意思是："2 的几次方等于 8？"  →  答案是 3
```

通用写法：

```
logₐ(b) = c   ⇔   a^c = b
（a 叫"底"，b 叫"真数"，c 是结果）
```

**三个必背例子**：

```
log₂(8)   = 3     因为 2³ = 8
log₁₀(100) = 2    因为 10² = 100
log₁₀(1000) = 3   因为 10³ = 1000
```

看出来了吗？`log₁₀` 其实就是在**数"这个数后面有几个 0"**：100 有两个 0 → log=2；1000 有三个 0 → log=3。

### 2.3 最重要的性质：乘法变加法（本讲主角）

```
log(x · y) = log(x) + log(y)     ← 核心！乘法变成加法
```

**这个性质从头推导一遍**（这是理解 LLM 取 log 的关键）：

设 `logₐ(x) = m`，`logₐ(y) = n`，翻译回指数就是：

```
a^m = x        a^n = y
```

那么 x 和 y 相乘：

```
x · y = a^m · a^n = a^(m+n)        ← 指数相乘的规则：底相同，指数相加
```

既然 `x·y = a^(m+n)`，那"a 的几次方等于 x·y"？答案就是 m+n：

```
logₐ(x · y) = m + n = logₐ(x) + logₐ(y)   ✓ 证毕
```

**两个附带性质**（由上面这条推出来）：

```
log(x / y) = log(x) − log(y)      （除法变减法）
log(x^n)   = n · log(x)           （次方变乘法）
```

### 2.4 自然对数 ln 和 e（认脸即可）

log 的"底"可以随便选（2、10……）。数学和机器学习里最常用**底 e**：

```
e ≈ 2.71828...    （一个特殊的无限不循环小数，和 π 一样著名）
ln(x) = logₑ(x)   （ln 就是"以 e 为底的对数"）
```

**e 是哪来的（一句话版）**：想象你把 1 块钱存银行，年利率 100%。如果利息"无限细分、每时每刻都在滚利"，一年后你的钱不会无限多，而是趋近于 **e ≈ 2.718 元**。这就是 e 的直觉——"连续复利"的极限。LLM 公式里的 `ln`、`exp`（e 的次方）、`sigmoid`（下一章概率里讲）全和它有关。

> 你不用会算 e，只要知道：**`ln` 就是"以 e 为底的对数"，性质和上面 log 完全一样。**

### 2.5 一个具体例子：把连乘安全地变成连加

假设你要算一个很小的数连乘 1000 次，比如 `0.5 × 0.5 × … × 0.5`（1000 个 0.5）：

```
0.5^1000 ≈ 10^(-301)   →  小到计算机直接当成 0（下溢）
```

但如果先取 log 再算：

```
log(0.5^1000) = 1000 × log(0.5) = 1000 × (−0.693) = −693
```

**−693 是个正常的数，一点都不会下溢。** 这就是 log 被到处用的根本原因——**它把"小到会爆掉"的连乘，变成"温和的连加"。**

### 2.6 它在 LLM 里的用途：交叉熵为什么取 log（第 3 讲）

第 3 讲里，交叉熵损失的推导，核心就是这一条链：

```
① 目标：让模型"看到训练数据的概率"最大
     P = p₁ × p₂ × … × p_T        ← 每个词的概率连乘

② 问题：连乘很多小数会下溢成 0（2.5 的例子）

③ 解法：取 log，把连乘变连加（性质 2.3）
     log(P) = log(p₁) + log(p₂) + … + log(p_T)

④ 技巧：log 是单调递增的（x 越大 log(x) 越大），
     所以"最大化 log(P)"和"最大化 P"是同一个答案

⑤ 最后取负号，把"最大化"变成"最小化"（这样能套优化器）
     Loss = −log(P) = −Σ log(pᵢ)
```

**翻译成人话**：模型每次猜对训练数据里的下一个词，概率 `pᵢ` 会越来越接近 1，`log(pᵢ)` 接近 0，损失就趋近 0；猜错时 `pᵢ` 很小，`−log(pᵢ)` 很大，损失很大，模型被"罚"得很重。**log 在这里负责两件事：防下溢 + 不改变"最优解"。**

> 顺带：缩放定律（第 2 讲）里那种"直线关系"的对数坐标图，也是 log 的功劳——`log(10^6)=6`、`log(10^9)=9`，把跨度几十亿的数据压成 6、7、8、9 的小刻度，才能画成一条直线。

> 小结（记这一句）：**log 把"乘法变加法"，`log(x·y)=log x+log y`；`ln` 就是底为 e 的 log。** LLM 用它把"连乘的概率"安全地变成"连加的损失"。

## 第 3 章：积分 ∫（从求和到积分）

### 3.1 一句话直觉

**积分就是"求和"的连续版。** 离散的东西（一颗颗豆子）用 Σ 加起来；连续的东西（一条曲线、一滩水）用 ∫ 积起来。

### 3.2 先复习求和 Σ，再平滑过渡到 ∫

**离散求和**（第 0 章学过）：把一个个**点**加起来。

```
总重量 = Σ 每颗豆子的重量
       = w₁ + w₂ + w₃ + … + wₙ
```

但现实里很多东西是**连续的**，不是一个点一个点，而是一条线、一片面。比如你想求"一根不均匀木棍的总重量"——它不是几个点，而是**每一毫米都有一点重量**，而且每处的重量还不一样。这时"一个个点加起来"就不够精确了。

**积分 ∫ 就是干这件事**：把连续的东西切成"无限薄的片"，每一片的量加起来，取极限。

```
∫ f(x) dx   =   把 f(x) 这条曲线下的面积"积"起来
```

### 3.3 几何含义：曲线下的面积

最直观的理解：`∫ f(x) dx` 就是**函数图像 f(x) 与 x 轴之间夹的面积**（从起点 a 到终点 b）。

```
  f(x)
   |      ████
   |    ██    ██
   |  ██        ██      ← 涂黑的部分 = ∫ f(x) dx
   |██            ██
   +──────────────→ x
   a              b
```

**怎么"算"这个面积？** 核心思想只有三步：

1. 把 [a, b] 切成很多窄条（每条宽 Δx，一个"小矩形"）；
2. 每个小矩形面积 = 高度 f(x) × 宽度 Δx，全部加起来；
3. 让条越切越细（Δx → 0），加起来的值趋近于一个极限，这个极限就是积分。

这其实就是第 0 章 Σ 的"无限细分"版：

```
Σ f(xᵢ)·Δx   （粗切）  →  ∫ f(x)·dx   （无限细，Δx 变成 dx）
```

所以看到 `dx`，就理解为"无限窄的宽度"，`∫ ... dx` 就是"把这些无限窄的小片全加起来"。

### 3.4 一个具体例子：均匀分布下的"面积 = 底 × 高"

假设 f(x) = 2 是一条水平线，从 x=0 到 x=3 积分：

```
∫₀³ 2 dx = 一个宽 3、高 2 的矩形面积 = 3 × 2 = 6
```

因为图像是平的，面积就是矩形面积，小学生都会算。**积分 = 面积**，这个例子最直观。

再举个"能算出结果的"：`∫₀¹ x dx`（f(x)=x，从 0 到 1），图像是一个直角三角形（底 1 高 1），面积 = ½ × 1 × 1 = **0.5**。（这一章不要求你会算，只要建立"积分=面积=求和极限"的直觉即可。）

### 3.5 它在 LLM 里的用途：期望 E[...]（第 4 讲 policy gradient）

第 4 讲一开头的目标就是"**最大化期望奖励**"，写作：

```
J(θ) = E[ R ]      ← 期望奖励
```

"期望"是啥？就是**加权平均**（第 5 章会细讲）。离散时：

```
E[R] = Σ pᵢ · Rᵢ        ← 每个可能结果 × 它的概率，再全加起来
```

当奖励 R 是**连续变化**的（而不是有限的几个值），Σ 就升级成 ∫：

```
E[f(x)] = ∫ f(x) · p(x) dx
```

**逐字翻译**：把"每个 x 的值 f(x)"乘上"x 出现的概率密度 p(x)"，对**所有连续的 x** 累加起来（积分）。这就是"连续版的加权平均"。

**为什么 policy gradient 里会出现 ∫？** 因为奖励、动作、概率在连续空间里都是连续量，要把"所有情况的贡献"都算进去，必须用积分而不是简单的 Σ。公式 `∇J = E[∇log π · R]` 里的 `E`，本质上就是一个 `∫`。

> 你不需要真的动手算积分（那要微积分技巧），只需要**看懂**：`∫` = 连续求和 = 曲线下面积，`E[...]` = 加权平均，`E[f(x)] = ∫ f(x)p(x)dx` 就是"把所有情况的贡献按概率加起来"。

> 小结（记这一句）：**积分 ∫ 是求和的连续版，几何上就是"曲线下的面积"；期望 E 是加权平均，连续时写成 ∫ f(x)·p(x)dx。** LLM 用 E[...] 表达"平均奖励/平均损失"。

## 第 4 章：矩阵计算（向量与矩阵乘法）

### 4.1 一句话直觉

**向量 = 一串数排成一行；矩阵 = 一张数表。矩阵乘法 = "把很多组'相乘再相加'一次性做完"。** LLM 里 90% 的运算，本质都是矩阵乘法。

### 4.2 向量：一串有顺序的数

```
v = [3, 5, 2]        ← 一个 3 维向量，就 3 个数
```

你前面学过：**一个词（token）的"向量"就是一串数**，比如 cute 的嵌入 `[0.512, 0.950]`（2 维向量，2 个数）。向量里的每个数叫"分量"或"维度"。

### 4.3 矩阵：一张数表

```
        ┌         ┐
W1  =   │ 0.512  0.950 │   ← 6 行 × 2 列
        │ 0.144  0.949 │
        │ 0.312  0.423 │
        │ 0.828  0.409 │
        │ 0.550  0.028 │
        │ 0.754  0.538 │
        └         ┘
```

这就是前面 `next_word_predictor.py` 里的 W1（嵌入表）。**矩阵的"形状"写成 `(行数 × 列数)`**，所以 W1 是 `(6×2)`：6 行（6 个词）× 2 列（2 个维度）。

### 4.4 矩阵乘法：唯一的规则（务必记死）

`C = A · B` 的规则只有一条：

> **C 的第 i 行第 j 列 = A 的第 i 行 与 B 的第 j 列，逐项相乘再相加。**

也就是"**行 × 列**"。看一个最小例子：

```
A = [1  2]      （1×2）
B = [3]         （2×1）
       [4]

A·B = 1×3 + 2×4 = 3 + 8 = 11    （结果是一个 1×1 的数）
```

**形状规则**：`(m×n) · (n×p) = (m×p)`——中间那个 n 必须对上，结果取"外层的 m×p"。

```
(1×2) · (2×1) = (1×1)   ✓ 中间 2 对上，结果 1×1
```

### 4.5 点积：向量相乘的特殊情况

两个**一样长**的向量，逐位相乘再相加，叫**点积**：

```
[1, 2, 3] · [4, 5, 6] = 1×4 + 2×5 + 3×6 = 4 + 10 + 18 = 32
```

**点积衡量"两个向量有多同向"**：都往一个方向 → 点积大（正）；垂直 → 0；反方向 → 负。这就是第 1 讲说的"相关度打分"的数学本质。

### 4.6 转置：把矩阵"翻个面"

```
A = [1  2  3]         Aᵀ（转置）= [1]
                                    [2]
                                    [3]
```


转置（右上角加 `ᵀ`）就是**行变列、列变行**。`Q·Kᵀ` 里的 `Kᵀ` 就是把 K 转置，好让"Q 的行"能和"K 的行"做点积。

### 4.7 它在 LLM 里的用途：一条线全串起来（复用你熟悉的例子）

还记得 `next_word_predictor.py` 吗？现在你能看懂它的每一行了：

**① 嵌入 = one-hot × W1（查表）**

```
[1, 0, 0, 0, 0, 0] · W1(6×2)
= 1×0.512 + 0×0.144 + … + 0×0.754   （第一维）
= [0.512, 0.950]                      （第二维同理）
```

形状：`(1×6) · (6×2) = (1×2)`。因为 one-hot 里只有一个 1，所以等价于"取 W1 的第 0 行"——**这就是"查表"的数学证明**。

**② 打分 = 嵌入 × W2（真正的点积）**

```
[0.512, 0.950] · W2(2×6)  →  6 个数，每个 = 嵌入 与 W2 某列 的点积
其中 cute 的打分 = 0.512×0.330 + 0.950×0.203 = 0.362
```

形状：`(1×2) · (2×6) = (1×6)`，得到 6 个词的打分。

**③ 注意力里的 Q·Kᵀ（第 1 讲最核心的矩阵）**

```
scores = Q · Kᵀ
形状：  (n×dₖ) · (dₖ×n) = (n×n)
```

`(n×n)` 是什么？就是**"每个词对每个词的关注度"那张方阵**——第 i 行第 j 列 = 第 i 个词对第 j 个词的相关度。整句话里"谁看谁、看多重"，全在这一张矩阵里。

**④ 多头注意力的维度账**（第 1 讲硬点，现在彻底看懂）：

```
X(n×512) → 投影 → Q、K、V 各 (n×64)         （512 劈成 8 个头，每头 64）
scores = Q·Kᵀ = (n×64)·(64×n) = (n×n)
head_i = softmax(scores/√64)·V = (n×n)·(n×64) = (n×64)
8 个头拼接 = (n×512)，再乘 W_O(512×512) = (n×512)
```

每一步都只是"**形状对得上 + 行×列**"，没有别的魔法。

> 小结（记这一句）：**向量是一串数，矩阵是一张数表；矩阵乘法就是"行 × 列、逐项相乘再相加"；点积 = 同向程度 = 相关度。** LLM 的嵌入、打分、QKᵀ 全是一次次矩阵乘法。

## 第 5 章：概率（softmax、交叉熵、KL 的源头）

### 5.1 一句话直觉

**概率回答"这件事有多可能发生"**，用一个 0 到 1 的数表示：0 = 绝不可能，1 = 一定发生，0.5 = 一半一半。

### 5.2 概率的三条铁律

```
① 每个概率在 0 到 1 之间：0 ≤ P(事件) ≤ 1
② 所有可能结果的概率加起来 = 1（一定会发生其中之一）
③ 互斥事件"或"的关系：概率相加
```

**例子**：扔一个公平骰子，6 个面每个概率 = 1/6。它们加起来 = `1/6 × 6 = 1` ✓。"扔出 1 或 2"的概率 = `1/6 + 1/6 = 1/3`。

### 5.3 期望 E：加权平均（概率的核心概念）

期望就是"**每个结果 × 它的概率，再全加起来**"：

```
E[X] = Σ xᵢ · P(xᵢ)
```

**例子（扔骰子）**：

```
E = 1×(1/6) + 2×(1/6) + 3×(1/6) + 4×(1/6) + 5×(1/6) + 6×(1/6)
  = (1+2+3+4+5+6)/6
  = 21/6 = 3.5
```

所以"扔很多次骰子的平均点数"是 3.5。**期望 = 长期平均**，这就是第 4 讲 `E[R]`（期望奖励）里 E 的意思。

### 5.4 softmax：把"任意一堆数"变成"概率"

LLM 最后要给每个词一个概率，但模型算出来的"打分"（logits）可能是 `0.362`、`1.138` 这种乱七八糟的数，甚至可能是负数。**softmax 就是把这些数变成"加起来 = 1 的一堆概率"。**

公式：

```
softmax(zᵢ) = e^(zᵢ) / Σ e^(zⱼ)
```

**逐字翻译**：第 i 个的概率 = "e 的 zᵢ 次方" 除以 "所有 e 的 z 次方之和"。

**为什么用 e 的次方？** 三个原因（现在你都能懂了）：

1. **变正数**：`e^x` 永远是正数（x 哪怕是 −100，`e^(−100)` 也是个极小正数），保证概率 ≥ 0；
2. **放大差距**：`e^x` 让大的更大、小的更小，赢家更突出；
3. **归一化**：除以总和，保证所有概率加起来 = 1。

**具体数字例子**（复用你熟悉的 cute 例子，6 个词的打分）：

```
打分：cute=0.362, fluffy=0.653, teddy=0.868, bear=0.499, runs=0.530, fast=1.138
```

第一步，每个取 e 的次方：

```
e^0.362 ≈ 1.436
e^0.653 ≈ 1.921
e^0.868 ≈ 2.382
e^0.499 ≈ 1.647
e^0.530 ≈ 1.699
e^1.138 ≈ 3.121
```

第二步，全加起来：`1.436+1.921+2.382+1.647+1.699+3.121 ≈ 12.206`

第三步，每个除以总和：

```
P(cute)   = 1.436/12.206 ≈ 0.118  (11.8%)
P(fast)   = 3.121/12.206 ≈ 0.256  (25.6%)  ← 最大，被选中
…
所有加起来 = 1  ✓
```

看到没，`fast` 打分最高（1.138），softmax 后概率也最大（25.6%），被 argmax 选中。**softmax 没有改变"谁最大"，只是把分数变成了能当概率用的数。**

### 5.5 交叉熵：衡量"猜得有多错"（第 3 讲）

前面第 2 章讲了 log，现在把概率和 log 合起来，就是交叉熵：

```
H = −Σ P(x) · log Q(x)
```

**逐字翻译**：
- `Q(x)`：模型认为 x 的概率（模型猜的）
- `P(x)`：真实概率（正确答案，通常是"只有正确那个词是 1，其余是 0"）
- `log Q(x)`：取对数（第 2 章的防下溢技巧）
- 乘起来、求和、取负号：得到"平均猜得有多错"

**具体例子**：假设正确下一个词是 `fast`，真实分布 `P = [0,0,0,0,0,1]`（只有 fast 是 1）。模型预测 `Q = [0.12, 0.16, 0.20, 0.13, 0.14, 0.25]`。

```
H = −( 0·log0.12 + 0·log0.16 + … + 1·log0.25 )
  = −log(0.25)
  = −(−1.386)
  = 1.386
```

关键点：因为真实分布 P 里只有 fast 是 1、其余是 0，所以**交叉熵最后只关心"模型给正确答案的概率"**，退化成 `−log Q(正确词)`。

- 模型给正确答案的概率越高（接近 1）→ `−log(接近1)` ≈ 0 → 损失小；
- 模型给正确答案的概率越低（接近 0）→ `−log(接近0)` 很大 → 损失大。

**这就是"损失函数"的全部含义：正确答案概率越大，损失越小，训练就是让这个损失越来越小。**

### 5.6 KL 散度：衡量"两个分布差多远"（第 4 讲）

KL 散度（Kullback-Leibler）回答："分布 P 和分布 Q 有多不一样？"

```
KL(P ‖ Q) = Σ P(x) · log( P(x) / Q(x) )
```

**直觉**：把 `P/Q` 取 log——如果 P 和 Q 完全一样，`P/Q = 1`，`log 1 = 0`，KL = 0；差得越多，KL 越大。**KL 永远 ≥ 0，越接近 0 说明两个分布越像。**

**第 4 讲的关键点：`KL(P‖Q)` 里的 P、Q 顺序很重要，不对称！**

- `KL(S‖T)`（reverse KL，S 在前）：会让 S **贴着 T 的"一个峰"**走，宁可放弃别的可能也要集中——这叫 **mode-seeking（求稳、追求单一答案）**；
- 反过来 `KL(T‖S)` 会把 T 的各个峰都"覆盖"到——这叫 mode-covering（求全）。

第 4 讲说"用 reverse KL 做蒸馏"、PPO 里的 `KL(π_θ‖π_ref)`，都是在用这个"别跑太远"的约束。

### 5.7 sigmoid：把"差距"压成 0~1 的概率（第 3 讲奖励模型）

第 3 讲奖励模型里出现过 `P = sigmoid(rᵢ − rⱼ)`。sigmoid 是什么？

```
σ(x) = 1 / (1 + e^(−x))
```

**它的作用**：把任意数（哪怕是 −1000 或 +1000）压到 **(0, 1)** 之间，正好当概率用。

```
σ(0)   = 1/(1+1) = 0.5      （输入 0 → 输出 0.5）
σ(3)   = 1/(1+0.0498) ≈ 0.95（输入大正数 → 接近 1）
σ(−3)  = 1/(1+20) ≈ 0.047   （输入大负数 → 接近 0）
```

**用在奖励模型里**：两个回答，一个奖励 rᵢ、一个 rⱼ，`sigmoid(rᵢ − rⱼ)` 就是"回答 i 比回答 j 更好"的概率。rᵢ 比 rⱼ 大越多，这个概率越接近 1——非常直观。

> 小结（记这一句）：**概率是 0~1 的数，加起来 = 1；softmax 把打分变概率；交叉熵 = −log(正确词概率)，衡量"错得多狠"；KL 衡量两个分布差多远；sigmoid 把任意数压成 0~1。** LLM 用 softmax 选词、用交叉熵当损失、用 KL 约束模型别跑偏。
